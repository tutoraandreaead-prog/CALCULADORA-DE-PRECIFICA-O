# Calculadora de Preço e Lucro

Calculadora gratuita de precificação para pequenos empreendedores: alimentação, artesanato, moda e beleza, revenda e serviços.

Mostra custo real por unidade, preço mínimo, sugestões de preço por margem de lucro, ponto de equilíbrio, meta de lucro mensal e retorno do investimento.

## Como usar
Acesse a página publicada, escolha a área do seu negócio e troque os valores de exemplo pelos seus. Os dados ficam salvos apenas no seu navegador.

## Tecnologia
Um único arquivo `index.html` (HTML, CSS e JavaScript), sem instalação.

Os valores de exemplo são estimativas e devem ser ajustados à realidade de cada região.
